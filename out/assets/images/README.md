# Assets Directory

## Images

Place your images in this directory. Recommended images to add:

### Required Images

- `og-image.jpg` - Open Graph image for social media sharing (1200x630px)
  - Currently using a placeholder SVG
  - Replace with a high-quality image featuring Ghana scenery or the experience

### Recommended Images (Optional)

- `hero-bg.jpg` - Hero section background
- `accra.jpg` - Accra city tour
- `aburi.jpg` - Aburi mountains
- `cape-coast.jpg` - Cape Coast heritage site
- `transport.jpg` - Luxury bus/transportation
- `hotel.jpg` - Hotel accommodation
- `cultural.jpg` - Cultural activities

### Image Optimization Tips

1. Use WebP format for better compression
2. Optimize with tools like TinyPNG or Squoosh
3. Keep file sizes under 500KB for web
4. Use descriptive file names
5. Always include alt text in components

## Icons

Place icon files (SVG, PNG) in the `icons/` subdirectory.

Recommended icons:

- `favicon.ico` - Browser favicon
- `apple-touch-icon.png` - iOS home screen icon
- `android-chrome-192x192.png` - Android icon
- `android-chrome-512x512.png` - Android icon (larger)

You can generate these from a single icon using tools like:

- https://realfavicongenerator.net/
- https://favicon.io/
