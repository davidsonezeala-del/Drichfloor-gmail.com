# Ghana Valentine's Experience 2026

Production-grade landing page built with Next.js 14, TypeScript, and TailwindCSS.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Configuration Checklist

Before going live, update:

- [ ] `src/lib/config.ts` - Payment URL
- [ ] `src/lib/config.ts` - Callback form endpoint
- [ ] `src/lib/analytics.ts` - Analytics service integration
- [ ] `public/assets/images/og-image.jpg` - Social media image
- [ ] `src/app/layout.tsx` - Website URL in metadata
- [ ] Add favicon files to `public/`
